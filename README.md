# 邊坡圖資編號查詢

輸入編號就能定位到 Google 我的地圖匯出的點位，可看街景、開 Google 地圖導航。底圖有國土測繪中心電子地圖、正射影像和 OpenStreetMap。

## 更換圖資

1. 在 Google 我的地圖（電腦版）點地圖名稱旁的「⋮」→「匯出至 KML/KMZ」
2. 圖層選「整份地圖」，勾選「匯出為 KML 而非 KMZ」，不要勾「保持資料在最新狀態」
3. 把下載的檔案改名為 `map.kml`
4. 在這個 repo 按「Add file」→「Upload files」上傳，同名檔案會直接覆蓋
5. 等一兩分鐘 GitHub Pages 更新後，重新整理頁面即可

也可以上傳 `map.kmz`（沒有 `map.kml` 時才會讀它）。
